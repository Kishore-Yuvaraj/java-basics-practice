# Java Basics Practice

A structured Java practice repository built while following a 9-month placement preparation roadmap targeting 3–5 LPA roles at TCS, Wipro, and Infosys.

## About
This repository contains hands-on Java programs organized lesson by lesson. Each file includes the problem statement as a comment followed by the solution.

## Project Structure
src/

├── lesson1/        # Java basics — Hello World, user input

├── lesson2/        # Variables and data types

├── lesson3/        # Operators — arithmetic, relational, logical

└── lesson4/        # Decision making — if, if-else, if-else-if

## Topics Covered

- Lesson 1: Java program structure, System.out.println, Scanner input
- Lesson 2: int, double, char, boolean, String — variables and data types
- Lesson 3: Arithmetic, relational, and logical operators
- Lesson 4: if, if-else, if-else-if ladder, nested if

## Tools Used

- Java 21 (Eclipse Temurin)
- IntelliJ IDEA Community Edition 2026
- Git and GitHub
